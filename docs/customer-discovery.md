## Next conversation: ten minutes

Speak with the contact or another developer who uses coding agents. Ask for a
specific recent example rather than agreement with our pitch:

1. When did an API change or teammate discovery last invalidate your work?
2. Which tools and agents were involved, and how did you learn about the change?
3. What manual workaround did you use? How long did it take, approximately?
4. What information could an agent share, and what must stay private?
5. Which part of a working publish → retrieve → patch flow would you actually use?

Ask them to try the narrow flow with synthetic data. Observe where they get stuck,
change one concrete feature based on feedback, and retest. A teammate interview
may reveal useful pain but should not be presented as an external customer pilot.
