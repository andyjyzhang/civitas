# Deep Agents change analyst

Planned TypeScript runner using the actual LangChain Deep Agents SDK. No runtime
code, dependencies, or commands exist yet. See [the integration design](../../docs/deep-agents.md).

Own explicit source-change investigations, per-run evidence files, specialist
analysis, a schema-validated context candidate, and reviewed publication through
Civitas MCP. Use the CLI's stdio bridge under one admitted publisher identity.
No direct access to relay application tables and no authority over receiving
developers' agents. A private checkpoint schema may support resumable runs.

Implement the real SDK plan, contract/impact specialists, bounded virtual files,
and a publication approval pause. Keep credentials outside model context. Verify
tool restrictions and source grounding, not just that a model returns text.

This is a showcase network participant. It must never become required for ordinary
agents to publish or retrieve context. Internal specialists are not independent
developer agents for demo counts. See [track strategy](../../docs/track-strategy.md).
